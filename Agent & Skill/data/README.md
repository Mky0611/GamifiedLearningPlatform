# Ví dụ nhập dữ liệu
26 record SAMPLE dạng JSON chỉ để xem cấu trúc, không phải danh sách từ chuẩn CEFR và chưa được phép auto-import. `cefrLevel=null` + reviewStatus `DRAFT_NOT_VALIDATED`; nguồn/giấy phép phải được kiểm tra trước khi public. Từ nhiều chữ như "continuous integration" phải được đưa sang flashcard/quiz, không chấp nhận trên board ghép chữ đơn nếu gameplay không hỗ trợ phrase.
